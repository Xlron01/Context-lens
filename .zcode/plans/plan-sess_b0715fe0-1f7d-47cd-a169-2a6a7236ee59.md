# AI Context Engine — Browser Extension (Phase 1)

## Overview
Chrome Extension (Manifest V3, TypeScript) that lets a user right-click any post/comment on X, Reddit, and (later) Facebook and ask **"Explain this"** or **"Who is replying to whom?"**. Phase 1 scope: Explain + Thread Understanding, built on a Provider-abstracted AI layer so no model lock-in.

## Tech Stack
- **TypeScript + Vite** (via `@crxjs/vite-plugin` for MV3 hot-reload)
- **Chrome Extension Manifest V3** (Chrome first; Firefox later)
- Providers: Gemini (primary, free tier), NVIDIA NIM / Groq / OpenRouter (fallback) — all behind one interface
- Storage: `chrome.storage.local` for user API keys (BYOK mode for Phase 1 — no backend)

## Repo Structure
```
src/
  manifest.ts
  background/          # service worker: message routing, provider calls
  content/
    collector.ts       # MutationObserver-based page scan
    adapters/
      adapter.ts       # PlatformAdapter interface → canonical node
      twitter.ts       # X adapter
      reddit.ts        # Reddit adapter
      generic.ts       # fallback heuristic adapter (covers FB partially)
    selection.ts       # right-click target resolution (which node was clicked)
  core/
    context-engine/
      graph.ts         # build thread tree from canonical nodes
      resolver.ts      # context resolution (parent, root post, sibling branch)
      budget.ts        # Level 0-3 context budgeting (truncate long threads)
    canonical.ts       # CanonicalNode type: {id, type, text, author, parentId, children, attachments, url}
  ai/
    provider.ts        # AIProvider interface: complete(task, context) → result
    gemini.ts / nvidia.ts / groq.ts / openrouter.ts
    router.ts          # task→model routing + fallback chain
    prompts/           # explain.ts, thread.ts prompt templates
  ui/
    popup/             # API key setup, provider pick
    panel/             # result panel (rendered near selection or side panel)
```

## Implementation Steps

### Step 1 — Scaffold
1. Init git repo + Vite + crxjs + TypeScript project
2. Manifest V3: content scripts on twitter.com, x.com, reddit.com; context menus; storage permission
3. Verify extension loads unpacked in Chrome

### Step 2 — Adapters + Canonical Structure
1. Define `CanonicalNode` (canonical.ts)
2. `TwitterAdapter`: parse tweet articles, replies, quote-tweets → canonical nodes (handle nested reply threads)
3. `RedditAdapter`: parse post + nested comment tree
4. `GenericAdapter`: heuristic fallback (closest text blocks with parent guesses) — first-pass Facebook coverage
5. Unit tests with saved HTML fixtures of real pages

### Step 3 — Context Engine
1. `graph.ts`: build tree, index by node id
2. `resolver.ts`: given target node → {directParent, rootPost, siblingBranch, relevantReplies} context package
3. `budget.ts`: token budget levels (L0 target, L1 parent+post, L2 branch, L3 capped semantic neighbors); hard cap ~8k tokens
4. Tests: 4000-comment Reddit fixture → resolver returns a bounded package

### Step 4 — AI Layer
1. `AIProvider` interface with structured output support
2. GeminiProvider (BYOK key from chrome.storage), then NVIDIA/Groq/OpenRouter
3. `router.ts`: Explain/Thread = cheap fast model; fallback chain Gemini → Groq → OpenRouter
4. Prompt templates for Explain and Thread tasks (Observed vs Inference vs Speculation separation; thread: who-replies-to-whom, point of disagreement, where misunderstanding started)

### Step 5 — UX
1. Context menu: "Explain this" / "Thread context" on selection inside supported sites
2. `selection.ts`: resolve right-clicked element → nearest canonical node
3. Result panel (shadow-DOM injected, avoids page CSS clashes) with loading states and provider errors
4. Popup: paste API keys, pick default provider, model status check

### Step 6 — Privacy basics
- Only the resolved context package (bounded) leaves the browser; redact author handles optional toggle

## Testing
- Vitest unit tests for adapters (HTML fixtures) + context engine
- Manual checklist per platform: explain a reply, explain a quote-tweet, thread on a 500+ comment Reddit post
